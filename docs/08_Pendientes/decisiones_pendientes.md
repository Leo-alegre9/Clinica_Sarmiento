# Decisiones pendientes

Decisiones importantes que condicionan el diseño de uno o más módulos y que **no** deben
resolverse por defecto/supuesto. Se listan aquí además de en las preguntas de cada módulo, para
tener una vista consolidada de "qué frena qué".
