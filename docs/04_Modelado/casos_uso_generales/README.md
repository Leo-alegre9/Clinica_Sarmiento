# Casos de uso generales

Los casos de uso detallados viven dentro de cada módulo (`03_Modulos/MOD-###.../casos_uso.md`).
Esta carpeta queda reservada para casos de uso que crucen varios módulos a la vez (por ejemplo,
"ciclo completo de un turno" una vez que Turnos, Recepción y Consultas estén refinados).

Por ahora no hay casos de uso transversales documentados: ver
[`../procesos_negocio/flujo_turno_hipotesis.md`](../procesos_negocio/flujo_turno_hipotesis.md)
para la hipótesis de proceso que eventualmente los originará, y
[`../../03_Modulos/MOD-001_Pacientes/casos_uso.md`](../../03_Modulos/MOD-001_Pacientes/casos_uso.md)
para los casos de uso ya documentados del primer módulo en refinamiento.
