# Diagramas

Los diagramas específicos de un módulo viven junto a ese módulo
(`03_Modulos/MOD-###.../diagramas.md`). Esta carpeta se reserva para diagramas transversales o
generales del sistema que no pertenecen a un único módulo.

## Diagramas transversales existentes

- [`../mapa_contexto.md`](../mapa_contexto.md) — contexto general del sistema y actores
  externos.
- [`../procesos_negocio/flujo_turno_hipotesis.md`](../procesos_negocio/flujo_turno_hipotesis.md)
  — proceso hipotético de punta a punta de un turno.
- [`../modelo_dominio/modelo_conceptual.md`](../modelo_dominio/modelo_conceptual.md) —
  entidades y relaciones conceptuales.

Todos son hipótesis de trabajo, no procesos ni modelos validados con el cliente.
