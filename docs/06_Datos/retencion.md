# Retención de datos

`PENDIENTE_DEFINICION` en su totalidad. No se recibió del cliente ninguna política de
retención. Preguntas abiertas relevantes:

- ¿Por cuánto tiempo debe conservarse la historia clínica de un paciente inactivo? (En
  Argentina, la normativa de historia clínica suele exigir plazos mínimos de conservación —
  a confirmar con asesoría legal, ver `INV` a crear si se confirma la necesidad).
- ¿Los datos de auditoría (`MOD-028`) tienen un plazo de retención distinto de los datos que
  auditan?
- ¿Los movimientos de caja tienen requisitos de retención vinculados a normativa impositiva?
- Relación directa con la política de backups — ver `RC-011`, `INV-006` y
  [`../03_Modulos/MOD-037_Backups/README.md`](../03_Modulos/MOD-037_Backups/README.md).

Este documento se completa cuando se resuelvan `INV-006` y las preguntas legales pendientes en
[`../01_Proyecto/restricciones.md`](../01_Proyecto/restricciones.md).
