# Modelo conceptual de datos

El modelo conceptual de entidades y relaciones se mantiene en un único lugar para evitar
duplicación: ver
[`../04_Modelado/modelo_dominio/modelo_conceptual.md`](../04_Modelado/modelo_dominio/modelo_conceptual.md).

Este archivo existe para completar la estructura documental prevista en la sección 7 del
pedido del cliente, y remite al documento real para no mantener dos copias que puedan
desincronizarse. Cuando el modelo de datos madure lo suficiente (post-aprobación de varios
módulos), este archivo puede pasar a contener el modelo físico/lógico derivado, distinto del
conceptual.
