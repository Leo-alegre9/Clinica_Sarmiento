# 00 — Gobernanza

Reglas de funcionamiento de esta documentación: cómo se nombran las cosas, qué estados existen,
cuándo un módulo está "listo" y cómo se gestionan los cambios sobre algo ya aprobado.

Leer en este orden antes de tocar cualquier documento de `/Docs`:

1. [`convenciones.md`](convenciones.md) — identificadores, idioma, origen de la información.
2. [`estados_requerimientos.md`](estados_requerimientos.md) — vocabulario de estados (módulos,
   preguntas, requerimientos).
3. [`definition_of_ready.md`](definition_of_ready.md) — checklist para `LISTO_PARA_VALIDACION`.
4. [`definition_of_done_documental.md`](definition_of_done_documental.md) — checklist posterior
   a la implementación.
5. [`control_cambios.md`](control_cambios.md) — Change Requests y quién puede aprobar qué.

Ver también el índice general en [`../README.md`](../README.md).
